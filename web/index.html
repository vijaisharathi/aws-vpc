📖 1. Abstract & Executive Summary

In modern cloud computing, multi-tier network segmentation is the cornerstone of defense-in-depth and enterprise infrastructure governance. This academic cloud engineering project demonstrates the complete design, automated deployment, and validation of an Amazon Web Services (AWS) Virtual Private Cloud (VPC) featuring segregated public and private subnets, dual Availability Zone redundancy, and zero-trust credential architecture.

🎯 2. Project Objectives

  • Automated Network Provisioning: Define custom VPC, subnets, route tables, internet gateways, and security groups declaratively in Terraform.
  • Strict Network Segmentation: Isolate public ingress resources from private data workloads.
  • Controlled Outbound Egress: Implement a NAT Gateway inside the public subnet for private instances.
  • Zero Trust Security & Least Privilege: Enforce security group chaining, eliminate SSH internet exposure, and store credentials in AWS Secrets Manager.

🗺 3. Architecture & Ideation Map

[INTERNET USER] → [INTERNET GATEWAY] → [PUBLIC SUBNET: 10.0.1.0/24 (AZ-a)] → [EC2 WEB SERVER] → [PRIVATE RDS MYSQL: 10.0.3.0/24 (AZ-b)]

🔢 4. CIDR Allocation & Subnet Segmentation Math

Class B root 10.0.0.0/16 partitioned into 3 Class C /24 blocks (251 usable IPs each after AWS 5-IP reservation).

🔄 5. Gateways & Routing Mechanics

IGW provides 1:1 bidirectional translation for public instances. NAT Gateway provides many-to-one stateful outbound egress for private subnets.

💻 6. Compute & Database Architecture

EC2 Ubuntu 22.04 LTS web proxy communicating over private VPC route to Amazon RDS MySQL 8.0 on TCP port 3306.

🔒 7. Security Center & Zero Trust IAM

Zero SSH exposure on internet; security group chaining; KMS storage encryption at rest; IAM role dynamic credential retrieval.

🧪 8. Testing Methodology & Validation

12 automated diagnostic test cases executing socket connect, route table traversal, and parameterized database CRUD validation.

📚 9. Technical Cloud Infrastructure Glossary

VPC, CIDR, Subnet, IGW, NAT GW, Security Group, IAM, Secrets Manager, IMDSv2.
